## 曾经的 ⛔ 约束（已解除其一）

### 地图与天气（步骤 6）

需要你提供：

1. **高德开放平台 Key**（个人开发者有免费额度，够试点：地理编码 + 路径规划）
2. **和风天气 Key**（免费版每日有调用上限）

拿到 Key 我才能把 `live_data: false` 换成真实路线与天气，并保留"额度用完自动降级"的行为。

### 小红书 / 大众点评（步骤 7）

技术上要先说清楚：

| 平台 | 有没有公开内容接口 | 能做什么 | 不能做什么 |
| --- | --- | --- | --- |
| 大众点评 | 没有面向第三方的公开 UGC 接口（需商家/合作方资质） | 生成**搜索跳转链接**；申请开放平台后用官方接口 | 抓取页面内容、存储用户评论原文 |
| 小红书 | 没有公开内容接口 | 同上（跳转 + 官方合作） | 同上 |

**建议的合规路径（分两步走）：**

1. **v1 先做「跳过去看」**：给用户一个"在小红书/大众点评搜『法海寺 姻缘』"的深链，**我们不存储、不摘录任何内容**。
   这样不涉及内容版权与平台条款，用户也能看到真实评价。
2. **再申请官方开放平台**（需企业资质与审核）。拿到接口后，再做真正的摘要（每条带平台 / 发布时间 / 观点类型），
   并保留 `evidence_type=ugc` 标记，回答里一律说"网友说法"。

这套做法和你之前定的边界一致：「只接入明确允许展示摘要并跳转原文的平台」。

## 上线后每周只看三个数

| 指标 | 在哪看 | 变差意味着 |
| --- | --- | --- |
| 来源可追溯率 | `GET /api/admin/temple/metrics` | 模型开始编，或资料来源坏了 |
| 降级率 | 同上 | 外部接口挂了 / 额度用完 / 数据缺失变多 |
| p95 时延 | 同上 | 下游变慢或数据量上涨 |
