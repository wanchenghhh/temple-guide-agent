# 腾讯云开通 · 手把手（从零到能打开网页）

> 目标：**30–40 分钟内**让 `http://公网IP:8787` 能打开、能对话。
> 全程你只需要：注册、点几下、复制粘贴命令。**不需要懂 Linux。**

---

## 第 0 步：先弄清"免费"这件事

腾讯云**没有永久免费的云服务器**，但有两条"不花钱"的路：

| 方式 | 说明 | 适合 |
| --- | --- | --- |
| **免费试用**（推荐先用） | 新用户可领 **1 个月** 的试用机（轻量应用服务器 / CVM 都有名额）。到期后**不会自动扣费**，但会**停机**，需要你决定续费或释放 | 内测验证 |
| **新用户特惠** | 不是免费，但很便宜（轻量 2核2G 通常是几十元/年级别），续费按原价 | 正式上线 |

⚠️ **三个必须知道的坑**：

1. **要实名认证**：大陆云服务器必须实名（个人身份证即可），否则不能开机。
2. **试用有期限**：到期停机，数据还在盘上，续费后可恢复；**别把唯一备份放在机器上**。
3. **名额会变**：免费试用的机型和库存随时调整，以官网为准。我这边看不到你的账号，**不能替你确认还有没有名额**。

> 买哪台：**轻量应用服务器（Lighthouse）** 比 CVM 简单，控制台更直观，同价位带宽更大。

**规格要求（重要）**：

| 项 | 最低 | 建议 |
| --- | --- | --- |
| 内存 | 1G（脚本会自动加 2G swap，能跑但构建慢） | **2G** |
| CPU | 2 核 | 2 核 |
| 系统 | Ubuntu 22.04 / 24.04 | 同 |
| 磁盘 | 40G | 40G |
| 地域 | 上海 / 北京 / 广州（离高德、和风、博查都近） | 同 |

## 第 1 步：注册与实名（10 分钟）

1. 打开 https://cloud.tencent.com → 右上角 **注册**
2. 用微信或手机号注册 → 登录
3. 右上角头像 → **账号信息** → **实名认证** → 选「个人认证」，按提示上传身份证 + 人脸识别
4. 认证通过后，控制台左上角能看到你的账号名

> 没有实名认证，后面买机/开机都会卡住。

---

## 第 2 步：领免费试用（5 分钟）

1. 搜索或直接打开：**https://cloud.tencent.com/act/free**（"免费试用"页面）
   > 如果这个链接变了：控制台首页 → 搜索框输入「免费试用」→ 进活动页
2. 在产品列表里找 **轻量应用服务器** 或 **云服务器 CVM**
3. 点 **立即试用** → 选：
   - 地域：**上海**（或北京/广州）
   - 镜像：**Ubuntu 22.04 LTS**（**不要**选"应用镜像"里的宝塔/WordPress，选**系统镜像**）
   - 规格：能选 2核2G 就选它；只有 1核1G 也行（脚本会加 swap）
   - 时长：免费试用通常是 1 个月
4. 确认订单（0 元）→ 创建。**创建时会给 root 密码**，或者你选"稍后设置密码"再重置。

**找不到免费试用名额怎么办**：
- 换一个地域试试（不同地域名额不同）
- 或者直接买最便宜的轻量（几十元/年），比花两小时找免费更划算

---

## 第 3 步：设置密码 + 放行端口（5 分钟）

### 3.1 设置 root 密码

控制台 → **轻量应用服务器** → 点进你的实例 → **重置密码**（设为 root 密码，记下来）→ 关机重启生效（或直接重置后即可用）。

### 3.2 放行 8787 端口（**最容易漏这一步**）

控制台 → 你的实例 → **防火墙**（CVM 叫"安全组"）→ **添加规则**：

| 协议 | 端口 | 来源 | 说明 |
| --- | --- | --- | --- |
| TCP | **8787** | 0.0.0.0/0 | 应用端口（内测阶段用） |

> 以后上了域名 + HTTPS，再放行 80 / 443，并把 8787 关掉。

### 3.3 记下公网 IP

实例列表里那个 **公网 IP**，例如 `123.45.67.89`。

---

## 第 4 步：连上服务器（2 分钟）

**Mac / Linux**：打开「终端」，输入（把 IP 换成你的）：

```bash
ssh root@123.45.67.89
```

第一次会问 `Are you sure you want to continue connecting?` → 输入 `yes` → 再输入刚才设的密码（输入时屏幕不显示，正常）。

**Windows**：用 PowerShell 或「Windows 终端」，命令一样。

看到提示符变成 `root@VM-...:~#` 就成功了。

---

## 第 5 步：把代码传上去（3 分钟）

**在你自己电脑上**（不是服务器上）新开一个终端窗口：

```bash
cd /Users/wancheng/Documents/00AIproducts/Personal-Agent-main
tar --exclude='.venv' --exclude='data' --exclude='.git' --exclude='__pycache__' \
    -czf /tmp/temple-guide.tgz .
scp /tmp/temple-guide.tgz root@123.45.67.89:/root/
```

> `scp` 会让你输一次服务器密码。传完大约 1–2 MB。

---

## 第 6 步：一键部署（5–8 分钟）

**回到服务器那个窗口**，粘贴这三行：

```bash
sudo -i
mkdir -p /opt/temple-guide && tar xzf /root/temple-guide.tgz -C /opt/temple-guide
cd /opt/temple-guide && bash deploy/tencent-cloud/bootstrap-local.sh
```

脚本会自动做完这些：

1. 装 Docker（如果没装）
2. 内存不足 2.5G 时**自动加 2G swap**（1核1G 也能构建）
3. 生成随机密钥（`AUTH_SECRET`、`HARNESS_ID_HMAC_KEY`、管理员令牌）
4. 构建镜像、启动容器、健康检查

**最后会打印一行**，务必记下来：

```
管理员令牌：ops:xxxxxxxxxxxx:users:read
```

---

## 第 7 步：填 4 个 Key（3 分钟）

```bash
nano /opt/temple-guide/deploy/tencent-cloud/.env
```

把这几行填上（`nano` 里用方向键移动，`Ctrl+O` 保存回车，`Ctrl+X` 退出）：

```ini
DEEPSEEK_API_KEY=sk-你的
AMAP_KEY=你的高德key
QWEATHER_KEY=你的和风key
QWEATHER_HOST=https://xxxxxx.re.qweatherapi.com      ← 必须带 https://
BOCHA_API_KEY=sk-你的博查key
```

保存后重启：

```bash
docker restart temple-guide
```

## 第 8 步：验证（3 分钟）

在服务器上：

```bash
bash /opt/temple-guide/deploy/tencent-cloud/smoke.sh http://127.0.0.1:8787 ops:你的管理员令牌
```

期望看到 **6 通过 0 失败**。

然后在**你自己的浏览器**打开：

```
http://123.45.67.89:8787
```

看到「寺庙寻访向导」页面 → 输入「我想求姻缘，从国贸出发」→ 出现推荐卡片 = **部署成功**。

## 第 9 步：日常维护（记住三条就够）

```bash
docker logs -f --tail 100 temple-guide     # 看日志
docker restart temple-guide                # 改完 .env 重启
```

```bash
crontab -e
# 加这一行：
0 4 * * * docker run --rm -v /opt/temple-guide/deploy/tencent-cloud/data:/data:ro -v /opt/temple-guide/backups:/backups alpine tar czf /backups/tg-$(date +\%F).tar.gz -C /data .
```

## 常见卡点对照表

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 浏览器打不开 | 防火墙没放行 8787 | 控制台 → 防火墙 → 加 TCP 8787 |
| `ssh: command not found` / 连不上 | IP 错 / 密码错 / 没开机 | 控制台确认实例"运行中"，重设密码 |
| 脚本里 `docker: not found` | 装 Docker 失败（网络或源问题） | 重跑一次；或 `apt-get update` 后重跑 |
| 构建时被 `Killed` | 内存不足 | 脚本已自动加 swap；仍失败就升到 2G |
| `llm: mock` | `.env` 里没填 DEEPSEEK key | 填上 → `docker restart temple-guide` |
| 行前总说"查不到" | `QWEATHER_HOST` 少了 `https://`，或 AMAP key 没填 | 改 `.env` → 重启 |
| 重启后记忆没了 | `data` 没挂到宿主机 | 确认 compose 里有 `./data:/app/data`（模板默认有） |

## 试用到期后怎么办

| 选择 | 说明 |
| --- | --- |
| 续费/买 2核2G | 数据在盘上不丢，重启即恢复；这是正式上线该做的 |
| 释放机器 | 先把 `/opt/temple-guide/deploy/tencent-cloud/data` 下载到本地（`scp -r`），否则记忆、指标、评测全丢 |
