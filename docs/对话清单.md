## 二、关键决策记录（谁定的、依据是什么）

| 决策 | 结论 | 依据 / 备注 |
| --- | --- | --- |
| 记忆保存期限 | **永久 + 可查看/修改/删除** | 你说"永久"，我补充删除入口；改动成本低（加过期字段即可） |
| 「平安」 | **默认项，不是标签** | 30 座里 29 座都标平安 = 没筛；改为不参与打分/排序 |
| 公众号 | **只当渠道，不当来源** | 公众号链接不可程序核验，写进来源会让"每月 404 抽查"失效 |
| 依据结构 | **拆两层**：场所事实（可核）+ 心愿说法（民俗） | 防止"殿宇有文献记载"被偷换成"在这儿求就灵" |
| 数据不够时 | **不补寺庙凑数，不编票价** | 报国寺（文化市场、无心愿）换成大悲寺；票价官方没写就不写 |
| 30 座数量 | 名单留 30、可推荐 27 | 遗址/不开放/文化市场不进推荐 |
| 上线方式 | **先邀请内测 2 周，不公开推广** | 73% 可推荐寺庙开放未核（当时），核心寺庙缺口大 |
| 第二城 | **先上线单城，再扩** | 架构参数化 1–2 天 + 数据 2–3 天（数据是大头） |
| 部署平台 | **腾讯云**（不用 Vercel） | Vercel 无持久盘/无常驻进程/10s 超时；腾讯云离外部接口更近 |
| 开源协议 | MIT，署名 `yangwancheng` | 你确认已取得权利转让后改为单一署名 |
