## 复核时只看四件事

1. **现状**：这座现在还能上香许愿吗？还是只算博物馆/遗址？（错了就整条作废）
2. **心愿依据**：标「口碑」的说法你认不认？标「文献」的殿名对不对？
3. **开放约束**：周一闭馆 / 要预约 / 正在修缮，有没有漏？
4. **来源**：标「未核实」的条目，你手上有官方链接的请补上；公众号只能当渠道，不能当引用。
