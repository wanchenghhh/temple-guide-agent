## 三、对脚本的 7 条批评：全部成立，已修复

| # | 批评 | 修复 |
| --- | --- | --- |
| 1 | `--source` 只验 HTTP 200，却写死 `kind: "official"`，会把携程/百科标成官方 | 新增 `--source-kind official\|media\|folk`，**默认 media**；只有 official 或 `--method phone` 才能升级 `sources_status` |
| 2 | 混淆「来源已核」与「开放信息已核」 | 新增 `open_verified_at` / `open_evidence`（method + grade + source + note），与 `checked_at` 分开 |
| 3 | `--open reservation` 与 `--reservation` 语义打架 | 拒绝自相矛盾组合（`--open reservation --reservation no` 直接退出 2） |
| 4 | `--closure` 整体覆盖，会抹掉已有规则 | 新增 `--merge-closure` 增量合并 |
| 5 | `open_note` 硬编码「电话核对」，会把网上查的写成电话核的 | 新增 `--method phone\|official_web\|media`，note 前缀随方法变化 |
| 6 | `checked_at` 一词三用 | 见 #2：开放信息用独立字段，不再动 `checked_at` |
| 7 | 附录说「问懂行的人就能补 basis」 | 改为：**没有 A 级殿堂依据，basis 就留空**；`claim_evidence` 固定 `folk`（红螺寺因为景区官网自述「送子观音是民间创造」，仍是 folk） |

新增测试 5 条（media 不升级、method 决定话术、closure 合并、自相矛盾拒绝、无来源不升级），共 12 条。

## 五、给下一轮的两条规矩

1. **门票数字只认 A 级页面原文**；A 级页面没列就写「官方页面未列价，以现场为准」，不抄 OTA。
2. **优先级按「会不会白跑」排，不按寺庙知名度排**：
   - 季节/防火闭园（妙峰山）
   - 平日不开或只开前院（通教寺、广化寺）
   - 双层票/园中园（卧佛寺、五塔寺、灵光寺）
   - 预约口径冲突（潭柘寺、云居寺、孔庙）

## 六、复核方式说明（重要）

本次全部为**联网资料核查**，`open_evidence.method = official_web`，**没有一条写成「电话核对」**。
数据里现在能区分三种证据：

| 字段 | 含义 |
| --- | --- |
| `open_evidence.method` | phone / official_web / media |
| `open_evidence.grade` | A（官方或电话）/ C（媒体/UGC） |
| `sources[].kind` | official / reference / media / folk |

这样将来有人问「这条开放信息可靠吗」，答案是可查的，而不是靠记忆。
